# Ο Κόσμος του Άγγελου

Μια σελίδα με παιχνίδια για τον Άγγελο (5,5 χρονών), στα ελληνικά.

Άνοιξε το `index.html` σε οποιονδήποτε browser, στο κινητό, στο tablet ή στον υπολογιστή.

## Τα παιχνίδια

- **Περιπέτεια:** Πίστα με εμπόδια σε 3D, στα σύννεφα ή στο διάστημα
- **Διάστημα:** Πλανήτες, Βρες τον πλανήτη, Στη σειρά
- **Κύβοι:** Χτίσε!, Μέτρα, Πρόσθεση, Τι ακολουθεί;, Ζευγάρια
- **Γράμματα & χρώματα:** Γράμματα, Χρώματα

Στην αρχή διαλέγει μασκότ: Αστρούλης, Άη Βασίλης, Χιονάνθρωπος, Ρομποτάκι, Σκυλάκι, Γατούλα, Δεινοσαυράκι ή Εξωγήινος.

Οι κρύσταλλοι, ο κόσμος που χτίζει και η πίστα όπου έφτασε αποθηκεύονται στον browser της συσκευής.
Η ανάγνωση των ερωτήσεων δουλεύει όταν η συσκευή έχει ελληνική φωνή.
